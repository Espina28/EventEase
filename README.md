# EventEase 🎉

EventEase is a comprehensive event planning platform designed to connect event organizers with trusted subcontractors. It empowers users to browse, book, and manage event services seamlessly, from weddings and birthdays to corporate events. Subcontractors can showcase their offerings, manage availability, handle transactions, and track progress through an intuitive dashboard. The platform ensures secure payments, real-time notifications, and reliable service delivery, fostering a trustworthy ecosystem for event planning. This solution addresses the challenges of finding reliable professionals, streamlining the event management process for both clients and service providers.

---

🚀 GET STARTED

- Clone the Repository
    `git clone <repository-url>`
- Install Frontend Dependencies
    `cd frontend/my-app-planease && npm install`
- Install Backend Dependencies
    `cd backend/Backend && mvn install`
- Run the Frontend
    `npm run dev`
- Run the Backend
    `mvn spring-boot:run`

---
🏷️ Requirements
- Node.js (for frontend)
- Java IDE (e.g., IntelliJ IDEA, Eclipse)
- JDK 17+
- Maven
- MySQL (for database)
